Instant Contextual Snippet Insertion 右クリックから即座に定型文・変数を挿入

A 100% local Chrome extension to insert category-organized templates with dynamic real-time variables directly from your right-click context menu. 右クリックメニューからカテゴリ別定型文とリアルタイム動的変数を組み合わせて即座に挿入できる、100%ローカル完結型Chrome拡張機能。

View on GitHub GitHubで見る How to Use 使い方を見る

Key Features 主な特徴

🔒

100% Local & Privacy-First 100% ローカル完結

No external server communication, tracking, or analytics. All data is stored locally in your browser. 外部サーバー通信、トラッキング、アナリティクスは一切なし。データはすべてブラウザ内に安全に保存されます。

📂

2-Level Context Menu 2階層コンテキストメニュー

Organize templates into categories for quick, effortless selection from the right-click menu. カテゴリごとの階層管理により、膨大な定型文も迷わず右クリックメニューから直感的に選択・挿入可能です。

⚡

Real-Time Dynamic Variables リアルタイム動的変数

Automatically converts dynamic variables like date, time, tomorrow, month-end workdays, and custom definitions. 日時、相対日付、月末稼働日、カテゴリ定義文などのタグをペースト時にリアルタイム自動変換します。

🎨

Material Design 3 Material Design 3 UI

Modern M3 UI with light and dark mode support, drag-and-drop variable chips, and live preview. ライト/ダークモード対応、変数のドラッグ＆ドロップ、リアルタイムプレビューを備えたモダンなUI。
