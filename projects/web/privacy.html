Privacy Policy プライバシーポリシー

100% Local Execution 100% ローカル完結

FlexPaste-Solo operates completely offline inside your Chrome browser. It does not send any data to external servers, cloud services, or remote analytics endpoints. FlexPaste-Solo はブラウザ内で完全に完結して動作します。外部サーバー、クラウドサービス、リモートアナリティクスへのデータ送信は一切行われません。

No Data Collection or Tracking データ収集・トラッキングなし

We do not collect, track, or share any personal information, browsing history, input content, or usage metrics. All template snippets and category configurations are stored strictly within Chrome local storage (chrome.storage.local). 個人情報、閲覧履歴、入力テキスト、利用状況データ等の収集や追跡は一切行いません。定型文テンプレートやカテゴリ設定はすべて Chrome のローカルストレージ（chrome.storage.local）に暗号化されずそのままブラウザ内にのみ保存されます。

Open Source & Transparency オープンソースと透明性

FlexPaste-Solo is built using standard Vanilla JavaScript with zero third-party framework or library dependencies. The source code is publicly accessible on GitHub under the MIT license. FlexPaste-Solo はサードパーティ製ライブラリを一切使用しない Vanilla JavaScript で構築されています。ソースコードは GitHub 上で公開されており、誰でも検証可能です。
